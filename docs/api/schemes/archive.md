# Archives: `zip:`, `tar:`, `archive:`

`archive+zip:` and `archive+tar:` are second scheme names of `ZipUri` and
`TarUri` (they pin the format, which `archive:` detects); `ArchiveZipUri` and
`ArchiveTarUri` stay importable as aliases of those two classes.
